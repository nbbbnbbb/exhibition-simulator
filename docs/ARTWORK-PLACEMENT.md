# 作品の数量・配置プレビュー・情報ラベル

## 数量と追加

作品編集の「数量（配置上限）」は、1つの展示プランで同じ作品を配置できる総数です。単品は1、同じ登録にまとめた複数枚は総数を入力します。作品カードに「配置数 / 数量」を表示し、上限では＋と右側の「追加配置」を無効にします。別案のプランは独立して数えます。

旧データで数量の欄自体がない作品は1として読み込みます。明示的な未入力（null）は数量未定のため、新規追加できません。旧プランに超過配置がある場合は消さずに読み込み、問題一覧で表示します。配置解除・移動・数量の増加で修正できます。既存配置より数量を減らす変更、数量超過を起こす作品付き可動壁の複製は拒否します。JSONを開いた際の旧配置も同様に保持し、読み込みだけで作品を削除しません。

## ポインターで配置

1. 左の作品カードの＋、または選択作品の「追加配置」を押します。この段階では保存データに作品を追加しません。
2. 3Dの壁面へポインターを動かすと、実寸の半透明プレビューが壁面に沿って移動します。固定壁と可動壁の表裏に対応します。通常10mm、Altで1mm刻みです。ガラス面は配置できません。
3. 空いている位置は緑、既存作品と重なる位置は赤で表示します。クリックで1点を確定します。重なりは作品の幅と高さの両方で判断し、壁端に収めた後にも再確認します。クリックを連続しても数量上限を超えません。
4. 平面図でも壁の内側にポインターを近づけて追加できます。平面図からの追加は中心高1500mmを初期値とし、天井・床へ収まるよう調整します。確定後は右側の数値で位置・高さを編集できます。
5. Escまたは「配置を中止」で取り消します。確定前のプレビューは履歴・自動保存・GLBに含めません。

## 複数点を行列で一括追加

このプランに追加できる残り数量が2点以上の作品には、カードに「まとめて配置」を表示します。追加する点数・列数・横の間隔・縦の間隔を指定し、「行列のプレビューを開始」を押します。行数は点数と列数から自動計算し、壁を正面から見て左上から右へ、次の行へ並べます。間隔は作品の端から端までのmmです。すき間0にも対応します。

3D・平面図で壁面を指すと、全点をまとめてプレビューします。壁端・床・天井では行列全体を一緒に収めます。残り数量を超える追加、全体が収まらない壁、1点でも他作品と重なる位置には追加できません。クリック1回で全点を確定し、その全点を選択します。1回のUndo/Redoで一括追加全体を戻せます。Escまたは「配置を中止」では1点も保存しません。従来の＋は1点ずつ追加する操作として引き続き使用できます。

## 配置済み作品の移動

3D・平面図の配置済み作品をドラッグすると、ポインターが指す別の壁へ移動できます。固定壁と可動壁の表裏に対応します。掴んだ位置を保って壁面に沿うプレビューを表示し、緑の位置で離すと確定します。赤い重なり位置、ガラス面、壁のない位置で離すと元に戻ります。Esc・ポインター操作のキャンセルでも元の配置を保持します。ドラッグ中は自動保存せず、確定時に1操作として保存するため、元に戻す操作で移動前へ戻せます。

同じ壁面の作品をShift/Ctrl＋クリックで複数選択すると、選択済みのどの作品からでも、修飾キーを離してドラッグすることで全作品をまとめて移動できます。通常のクリックで選択済み作品をつかんでも複数選択を保持します。Shift/Ctrl＋クリックは選択の追加・解除に使います。未選択の作品を通常クリックすると、その作品だけを選択します。

まとめて移動する際は、作品間のすき間・左右の並び・下端高さの差を保ちます。3Dでは共通の横・縦の移動量を適用し、平面図では高さの関係を保って横移動します。別の壁や可動壁の表裏へ移す場合も、壁を正面から見た左右の関係を維持します。壁端・床・天井では全体を一緒に収め、個別に位置をずらしません。全体が壁の幅・高さに収まらなければ確定できません。

移動中は全作品のプレビューを表示し、つかんだ作品以外の1点でも他作品と重なると全体を赤で表示します。その位置で離しても、全作品が元の位置に戻り、保存やUndo履歴を変更しません。移動対象同士は、移動後の座標で重なりを判定します。異なる壁面に分かれている作品を一度にドラッグした場合は、同じ壁面から選択するよう案内します。成功したグループ移動は1回のUndo/Redoで全作品を戻せます。

作品のIDと数量を変えずに移動するので、数量上限に達した作品も移動できます。平面図では下端高さを維持し、移動先が低い場合のみ収まる高さへ制限します。3Dは掴んだ位置と高さを保ちながらポインターに追従します。数値による位置変更でも、他作品と重なる変更は拒否します。既存の重複配置を読み込んだ場合は、消さずに問題一覧で表示します。別々の壁面同士の立体的な額縁の干渉は判定しません。

## 遠景での描画

俯瞰カメラでは距離に応じて手前の描画範囲を調整し、遠方での奥行き精度を確保します。作品画像面には小さな深度補正を加え、額・壁とのちらつきを抑えます。実寸、壁からの物理的な距離、GLBの形状座標は変えません。壁による遮蔽と奥行き判定は有効なままです。歩行・VRでは元の30mmの近接描画範囲を使います。

## 整列・均等・行列配置

同じ壁面の作品をShift/Ctrl＋クリックで複数選択し、右の配置パネルで操作します。可動壁の表面・裏面はそれぞれ別の壁面として扱います。左右は壁を正面から見た向きです。

- **選択作品の整列**：左端・左右中央・右端・上端・上下中央・下端の6種類。選択した作品全体の外接範囲の端・中央が基準です。2点以上の選択が必要です。たとえば上端揃えでは、最も高い位置にある上端へ全作品の上端を揃え、横位置を保持します。
- **横・縦の均等配置**：方向を選び「両端を固定して等間隔」を押すと、その方向の両端の作品を固定し、額を含む作品の端から端のすき間を均等にします。幅・高さが異なる作品にも対応します。「作品間のすき間」にmmを入力して「適用」を押す場合は、横は左端、縦は上端の作品を固定して順に並べます。もう一方の方向の位置は保持します。
- **行列配置**：「行列に並べる」を開き、列数・列のすき間・行のすき間を指定して適用します。行数は対象数から自動計算します。選択した順に左上から右へ、次の行へ並べます。各列の最大幅・各行の最大高さを使い、各作品をセルの中央に揃えます。異寸法の作品では、指定のすき間は列・行の領域間の値になり、小さい作品同士の実際のすき間は広くなります。対象範囲の中央付近へ配置し、必要な場合は行列全体を壁内に寄せます。

均等・行列配置は、1点だけ選択している場合はその壁面の全作品を対象にします。この場合の行列の順序はプラン内の配置登録順です。0mmのすき間も指定できます。座標は1mm単位のため、奇数寸法や割り切れない間隔では端・中央・すき間に最大1mm程度の差が生じます。

壁からはみ出す配置、作品同士が重なる配置、異なる壁面をまとめた操作は、理由を表示して一括で取り消します。未選択作品との重なりも確認します。成功した操作は1回の「元に戻す／やり直す」で戻せて、自動保存・JSON・設営CSV・3D表示に反映されます。

## 右クリックで情報表示・配置削除

平面図・3Dの作品を右クリックすると、作品名・作家・制作年・実寸と操作メニューを表示します。「作品情報を表示」で、数量・展示方法・寸法の確度・梱包・備考などの登録情報を確認できます。情報画面から編集画面へ進むこともできます。

「作品の配置を削除」は、右クリックしたその1点の配置だけをこのプランから削除します。作品ライブラリや他の配置は保持します。可動壁の右クリックメニューでは、確認後に壁と両面の作品配置を削除し、作品ライブラリは保持します。どちらもUndoで復元できます。

メニューはEsc・外側のクリック・画面切替で閉じます。矢印キーで項目を移動し、Enterで実行できます。3Dで作品・可動壁を右クリックすると、その位置からのカメラの平行移動を開始しません。

## 作品情報

画面下の「作品情報」でON/OFF、「表示項目」で作品名・作家・制作年・実寸・数量・備考などを個別に選びます。空欄は表示しません。3Dでは作品の脇に壁面と同じ向きのラベルを表示します。左右が埋まる場合は上下の空きを探し、適切な場所がない場合は壁面内へ寄せます。壁面が密集するとラベル同士が重なる場合があります。平面図にも選んだ情報を表示します。

表示設定はプロジェクトに保存し、JSON書き出し・再読み込み・元に戻す操作に対応します。ラベルは確認用表示で、実際のキャプションの設営位置・寸法を定義するものではありません。GLBには含めません。3Dの世界座標内に置くため、歩行・VRでも同じ位置に表示されます。実機ヘッドセットでの可読性は未検証です。

## 検証

```powershell
npm test
npm run build
# アプリを http://127.0.0.1:5173/ で起動して実行
node scripts/artwork-placement-test.mjs
node scripts/artwork-move-test.mjs
```

数量、旧データ移行、重なり、壁端、可動壁表裏へのポインター交差、ラベル項目とJSON往復を単体テストします。ブラウザー検証は通常利用とは別の保存領域を使い、実際のクリック・プレビュー・配置拒否・数量編集・ラベル表示・再読み込みを確認します。結果と確認画像は `test-results/artwork-placement/` に保存します。

整列・均等・行列配置は、異寸法・縦横・可動壁表裏・奇数寸法・端数行・壁際・不正入力・重なり拒否を単体テストし、ブラウザーでは6種類の整列、縦横の間隔、行列、選択範囲、Undo/Redo、自動保存と再読み込み、狭い画面の入力欄を確認します。結果と確認画像は `test-results/artwork-arrangement/` に保存します。以下はビルド済みファイルをPlaywright内で読み込むため、サーバーの起動は不要です。既存のブラウザー保存データは変更しません。

```powershell
npm run build
node scripts/object-actions-test.mjs
node scripts/artwork-arrangement-test.mjs
node scripts/artwork-group-move-test.mjs
```

複数ドラッグのブラウザー検証では、平面・3Dの別壁移動、全作品のプレビュー、非選択作品との衝突拒否、Esc・ポインター取消、1回のUndo/Redo、保存、可動壁表裏への移動を確認します。結果は `test-results/artwork-group-move/` に保存します。
