# 日照・照明シミュレーション

2026-11-04 追加。右側の「照明・日照」タブ、または3Dビュー下の「照明・日照」から操作します。照明条件はプランごとに保存され、複製・JSONの入出力・ブラウザー保存に含まれます。

## 使い方

1. 日付と時刻（JST）を指定します。「春分・夏至・秋分・冬至」で代表日へ切り替えられます。年ごとの正確な二十四節気の時刻を指定する機能ではありません。
2. 太陽高度・方位角と一日の高度曲線を確認します。方位角は真北0°、東90°、南180°、西270°です。図面上端が真北、3Dの+Xが東、-Zが北です。
   方角図は真北を上にし、太陽の位置、室内へ向かう光の矢印、水平面で影が伸びる方向を表示します。影の方位は太陽の反対方向です。朝夕・季節によって方向が変わり、低い太陽ほど影が長くなります。直達光のない条件では、その旨を表示します。
3. 太陽光の強度・影の柔らかさ、屋外の天空光を調整します。北窓・南窓側から室内を見るボタンで採光状態を確認できます。
4. スポットとレール定常光のON/OFF、色温度（1,800〜10,000 K）、基準照度（0〜3,000 lx）を個別に調整します。スポットは配光角と光の縁の柔らかさも設定できます。
5. 作品を選択すると、その表面中心の概算照度を表示します。選択がない場合は主室の基準作業面（高さ800 mm）です。直達光・天空光・スポット・定常光・間接反射の内訳を表示します。
   「直達光」の状態には、北／南窓から届くか、天井・外壁・窓枠・梁・柱・中二階・可動壁のどれによる影かを表示します。可動壁は名称も表示します。作品面が太陽に背を向ける場合、夜間、南側周辺建物による遮蔽も区別します。可動壁の移動時は、その上の作品の測定位置・面の向きも更新します。
6. 「床・壁の反射光」で、床・壁から天井・梁下面への反射を簡易補正できます。標準100%、0%で補正OFF、最大200%。実測の反射率ではありません。既存の保存データにも標準値を補います。
7. 「画面の露出」はモニター上の明るさを調整する機能で、照度の数値を変えません。

「全光源OFF」は自然光・スポット・定常光をすべて停止します。作品画像にも照明が適用され、暗所で画像だけが光り続けることはありません。編集用の選択枠・配置ラインなどは表示されます。

GLBには灯具の形状も含めます。照明条件の編集データはプロジェクトJSONに保存され、GLBで同じ照明の見え方を完全再現するものではありません。

## 計算と描画

### 可動壁と床ライン

ビュー下と「可動壁」タブの「可動壁の床ライン」で、3D・平面の点線を同時にON/OFFできます。表示設定はこのブラウザーで保持します。点線は編集用で、影を落としません。非表示にしても可動壁本体とその遮光は残ります。

可動壁は窓からの直射を遮り、移動・寸法変更でシャドウマップを更新します。天空から窓へ入る散乱光にも、窓ごとの広角光源による柔らかい遮蔽を追加しています。散乱光は面光源35%と影を付ける広角光源65%の混合で、窓から3 mの基準点で従来の照度に合わせる簡易モデルです。間接反射の補正は大域的であり、壁移動による多重反射の再計算は行いません。

可動壁自体も影を受けます。太陽側の面と裏面では入射角による直達照度が異なり、他の壁・梁などの影も重なります。概算の直達光は、測定点から太陽方向へ追跡し、最初に交わる不透明な部材を判定します。窓の縦枠・横枠は3Dと照度計算で同じ寸法データを使用します。天空光の面積積分では、標本点がすべて縦枠に重なる偏りを避けるため、行ごとに横位置をずらしてサンプリングします。

`node scripts/partition-lighting-test.mjs` で表示切替・表示設定の保持・可動壁による直射／散乱光の遮蔽・移動による影の更新を実画面7項目で確認できます。結果は `test-results/partition-lighting-report.json` に保存します。

- 太陽位置は[NOAAの近似計算式](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)を実装。日付・閏年・JST・緯度経度から、均時差・赤緯・時角・高度・方位角を求めます。天気の実況取得や大気屈折の精密計算は行いません。日没で背景を切り替えず、太陽高度に応じて明色から夜色へ連続補間します。天空光も太陽高度−18°まで滑らかに減衰する薄明の近似です（[薄明の角度区分](https://aa.usno.navy.mil/faq/RST_defs)を参照。明るさの曲線自体は表示用の仮定）。
- 晴天時の法線直達照度を90,000 lx基準とした簡易モデルで、高度による減衰・強度倍率・南側遮蔽・ガラス透過率を適用します。実際の天候を予測する値ではありません。
- 直射はDirectionalLightとシャドウマップで表現し、不透明天井・外壁・柱・梁・可動壁で遮光します。採光未確認の扉の模式的な開口には、描画用ではない遮光面を置いています。
- 天空光は窓面からの面光源、レール定常光は下向きの線状面光源で近似します。外から天井を通過する全天光は与えません。室内反射の補正に限り、床側の成分を強めた半球型の光を使います。
- [Three.jsのSpotLight](https://threejs.org/docs/pages/SpotLight.html)はcdと逆二乗減衰を使用。設定したlxになるよう各器具の光軸上の壁面点へ校正します。配光角は全角で指定します。
- レール定常光は、主室の基準点（X=主室幅/2、Z=(全長−8,620)/2、高さ800 mm、上向き）の遮蔽前照度が設定lxとなるよう、面光源の輝度を校正します。他の器具の寄与や遮蔽がある測定点の照度は設定値と異なります。
- 概算照度は面光源の面積積分、スポットの円すい配光、可動壁・柱・梁・中二階等の遮蔽を簡易計算します。間接反射は人工照明と窓から入る直射・天空光に応じた室内の半球型光源で近似し、天井・梁の下面を強め、上向きの床面へは弱めに加えます。全光源OFFではこの補正もゼロです。
- シャドウマップは構造・光方向が変わったときに更新し、静止時の再計算を抑えます。色温度・照度・画面露出だけの変更では不要な影の再計算を避けます。

## 検証

`npm test` に含まれる照明専用12テストで太陽位置、方位、南側遮蔽、窓と天井、光源のlx校正、全光源OFF、色温度、露出、可動壁、プラン別保存と旧JSON移行を確認。

追加の `tests/solar-shadows.test.mjs` の9テストで、朝夕の光と影の方角、東西向きの面への入射、夏冬の直射の到達範囲、天井・外壁・窓枠の遮光、可動壁の移動・幅・高さと表裏の受光差、遮蔽理由、3D光源の方向と時差変更時の影の更新を確認します。窓枠については実際のThree.jsの箱形状への光線交差と概算結果も照合します。

`npm run test:lighting` ではChromeの実描画と保存データを17項目確認しています。操作ログだけでなく、WebGLキャンバスから実ピクセルを読み取っています。

- 全光源OFF：作品・壁の検査領域の平均輝度が約149からほぼ0へ低下。
- 色温度：2,700 Kと9,000 Kで、描画された作品の青／赤比が変わることを確認。
- 閉じた天井：冬至正午、南側遮蔽を外し天空光を0にしても、北窓側の床はほぼ0のまま。屋根からの直射漏れがないことを確認。
- 南窓：同じ条件で南窓側へ移動すると床へ直射が入り、遮蔽高度を80°へ戻すと暗くなることを確認。
- 夏至早朝の北窓への直射可能性、夜間の自然光0、プラン複製・独立編集・JSON入出力・IndexedDB復元、幅390 pxの操作画面も確認。

結果は `test-results/lighting-report.json`、確認画像は `test-results/lighting-*.png` に出力します。これらはGitの対象外です。

日没の背景と反射光の補正は `node scripts/lighting-reflection-test.mjs` で7項目を確認できます。夜間の天井・梁が補正により明るくなること、補正強度、人工光の反射が時刻で変わらないこと、日没前後の背景の連続性、夜への減光、薄明表示、設定の保存復元を実画面で検証します。結果は `test-results/reflection-report.json` です。

## 残る制約

この機能は展示計画用の**簡易比較シミュレーション**です。実測照度・器具のIES/LDT配光・正確な周辺の遮蔽角・ガラス仕様・表面反射率が未提供です。多重反射・測色・熱・紫外線・年間累積露光は計算しません。色温度から表示色への変換も近似です。

定常光の影は表示上で省略し、天空光の影は広角光源で近似するため、特に可動壁や中二階付近では、表示と概算値に差が出ます。スポットと直射の影は描画します。実際の作品保護照度や施工・器具選定は、現地測定と器具資料で確認してください。HMD実機での新照明の性能確認は未実施です。
