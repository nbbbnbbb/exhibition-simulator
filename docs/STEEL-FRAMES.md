# 軽量鉄骨フレームとビニール膜

左の「鉄骨」タブで組立形状を選び、「＋ 鉄骨フレームを追加」を押します。追加したフレームを一覧・平面図・3Dで選択すると、右側で寸法と位置を編集できます。

## 3Dでラインを描く

「鉄骨」タブの「3Dでラインを描く」から、1本ずつ鉄骨部材を直接配置できます。

1. 「作業平面を配置」を押すと、3Dビューに半透明の仮想平面とXYZ移動ハンドルが現れます。この段階ではラインを作りません。
2. 平面本体をドラッグして位置を決めます。赤X・緑Y・青Zの矢印は、その軸に沿って移動します。「作業平面を拡大」で見やすい視点にでき、「作業平面の座標」を開けば中心XYZを数値でも指定できます。ドラッグ途中のEscやフォーカス喪失は移動を取り消します。
3. 「この平面でラインを描く」またはEnterで位置を確定し、始点、終点の順にクリックします。1本のラインとして確定し、「終点から続けて描く」がONなら、その終点が次の始点になります。
4. 「作業平面を動かす」で描画を一時停止し、平面を再配置できます。水平面XZ・垂直面XY・垂直面YZの切替時も、位置を確認・確定してから描画を再開します。未確定の始点は保持されるため、面の位置・向きを変えて立体的につなげられます。
5. 通常は10 mm、Altを押すと1 mm刻みです。既存のライン端点や組立フレームの接合点付近では端点に吸着します。吸着先は作業平面の外にある点も選べます。
6. 描画中のEnter、Esc、または「ライン配置を終了」で終えます。始点だけの未確定ラインは保存しません。確定済みのラインは残り、Undoで1本ずつ戻せます。「終点から続けて描く」をOFFにすると、1本で終了します。

配置・描画中は右ドラッグで視点回転、Shift＋右ドラッグで平行移動、ホイールで拡縮できます。作業面と視線が平行な場合は、視点を回転してから配置してください。緑のプレビューは配置可能、赤は配置できない状態を示します。ラインの長さは100〜30,000 mmです。建物の境界・床・天井による配置制限はなく、建物外や負のXYZ座標にも配置できます。

ラインを選択すると、右側で始点・終点それぞれのXYZ座標と部材断面を編集できます。座標は部材の中心線の端点です。水平・垂直・斜めのラインに対応し、平面図・3Dでのドラッグ、複製、削除、プラン複製、自動保存、JSON・GLB出力も利用できます。「この終点から描き続ける」で既存のラインの先へ追加できます。接続後も各ラインは独立して編集されます。仮想作業平面と移動ハンドルは編集用のガイドで、GLBには含めません。

## ラインから生成した面に膜を貼る

同じ平面でラインを閉じると、「ラインから生成した面」に自動で面が現れます。水平面・垂直面・斜めの面に対応し、ボックスは各面を検出します。途中で接続・交差するラインがあれば領域を分割し、凹形や内側に穴のある輪郭も扱えます。輪郭が開いている場合や、頂点が同じ平面にない場合は面を作りません。

左側の面一覧の「膜」をONにするか、一覧または3D上で面を選択し、右側の「この面に膜を貼る」をONにしてください。面ごとに膜の色・不透明度を変更でき、「この面の膜を外す」で取り外せます。平面図でも面と膜を表示します。膜を貼る前の面は、3D上で淡い色で表示します。

ラインの編集で閉じた領域の形が変わると、膜も追従します。輪郭が一時的に開いた場合は膜を非表示にし、同じ境界ラインで閉じ直すと設定を復元します。境界のラインを削除すると、その膜設定も削除し、Undoで戻せます。膜の設定はプランごとに保存し、JSONの保存・読み込み、プランの複製、GLB出力に含まれます。GLBには実際に貼った膜を含め、膜を貼る前の面のガイドは含めません。

## 配置と編集

- 組立形状のプリセット：矩形、ボックス、門形（下辺なし）、三角形。
- 部材断面のプリセット：C形 65 × 30 × 10 × 0.8、U形 67 × 30 × 0.8、角パイプ 25 × 25 × 1.2、L形 30 × 30 × 1.6（mm）。断面は輪郭を押し出して表示し、角パイプは中空です。寸法は表示用の初期設定です。
- フレーム幅・高さ・奥行は部材断面を含む外寸。平面形状は奥行0として保存し、部材そのものの厚みは残ります。幅・高さ・奥行の変更で、登録した組立形状を各軸方向に拡縮します。
- X / Zは配置範囲の中心、下端高さは床から最下端までの距離。原点・方向は建築と共通で、+Xは東、+Zは南、+Yは上です。回転角は上から見たY軸回りの角度です。
- 平面図・3Dのフレームをドラッグすると、配置ラインに制約されず床面方向に移動します。通常10 mm、Altを押すと1 mm刻み。Esc、フォーカス喪失、ポインター操作の中断で取り消します。「フレームを正面から確認」で3Dを拡大できます。
- 鉄骨フレーム・ラインの建物範囲による制限はありません。建物外・床下・天井の上にも配置できます。平面図と「全体を表示」は建物外の鉄骨も含む範囲を表示します。
- 「フレームを複製」「フレームを削除」に対応。選択中はDeleteでも削除できます。Undo / Redoでフレーム・膜・登録内容を戻せます。

## ビニール膜

右側の「ビニール膜」で貼る面を選びます。「全ての面に貼る」「全て外す」も使用できます。ボックスは正面・背面・左面・右面・上面・下面を個別に指定できます。膜の色と不透明度（0〜100%）はフレームごとの設定です。膜はフレームの移動・回転・寸法変更に追従します。

膜は部材の接合点を結ぶ平面として両面表示します。門形など周囲を部材で閉じていない形状には、初期状態で膜面を用意していません。組立形状を切り替えると面の対応が変わるため、貼り付け面の選択を解除します。

## 独自の組立形状

「独自の組立形状を登録」を開き、プリセットを元に編集できます。

1. 頂点座標を1行に `X, Y, Z`（mm）で入力します。頂点番号は行の順に1から始まります。
2. 部材の接続を1行に2つの頂点番号で指定します。
3. 膜を貼れる面を、周囲の頂点番号を時計回りまたは反時計回りに並べて1行で指定します。面を登録しなくてもフレームとして利用できます。
4. 名前を付けて登録すると「鉄骨」タブの組立形状に追加されます。

台形の例：

```text
頂点座標       部材の接続   膜を貼れる面
0, 0, 0        1, 2       1, 2, 3, 4
3000, 0, 0     2, 3
2400, 2000, 0  3, 4
600, 2000, 0   4, 1
```

頂点は3〜64個、部材は1〜128本、面は最大32面。すべての頂点を部材に接続し、重複部材を避けてください。各面は周囲を部材で囲った同一平面の凸多角形とします。凹形の面は部材で複数の凸面に分割して登録してください。独自形状は全プランで共通です。全プランで未使用の登録形状は、ライブラリで削除できます。

## 独自の部材断面

フレームを選んで「独自の部材断面を登録」を開きます。部材中心を原点に、厚みを含む輪郭の `X, Y`（mm）を順番に入力してください。交差しない3〜32頂点、各軸±500 mm以内の多角形に対応し、穴のある独自断面には対応しません。既存の角パイププリセットには穴があります。

登録断面は全プランから利用できます。選択中のフレームに収まる場合は、その断面へ切り替えます。

## 保存と制約

フレームと膜はプランごと、独自の組立形状・部材断面はプロジェクト共通で保存します。自動保存、全プロジェクトのJSON書き出し・読み込み、プラン複製・比較、GLB出力に含まれます。GLBはメートル単位で、膜は両面の半透明材質として出力します。旧JSONには空のフレームとライブラリを補完します。

現在の機能は展示の形状・配置・見え方の検討用です。膜のたるみ・張力・しわ、固定金物、構造強度、部材の切断・接合詳細は再現しません。鉄骨・膜と可動壁・柱・梁・作品との干渉、歩行時のフレームとの衝突、膜による照度の再計算は未対応です。設営CSVは作品用で、鉄骨の部材表は含みません。

## 検証

```powershell
npm test
npm run build
npm run test:steel
npm run test:steel-lines
npm run test:steel-line-faces
```

`test:steel` は独立したChromeセッションでビルド済み画面を検証します。実利用中のブラウザー保存領域には触れません。結果・スクリーンショット・往復用JSON・GLBは `test-results/steel-frames/` に保存します（Git対象外）。
