# 天井の梁・可動壁レール・照明レール

## 写真と指示の反映

- **可動壁レール付き梁**：平面の可動壁ラインを基準とし、各ラインの始終点と天井レールの中心線を一致させます。横断・中央縦線・西室のラインを共通の `project.rails` から生成します。床ラインの座標は変更していません。
- **コンクリートのみの梁**：レール付き梁の間の横断梁、および照明レールを支える長手方向のコンクリート梁を残しています。横断梁は可動壁ライン間に置き、建築寸法の「梁間隔」を目安に間隔を分割します。「梁間隔」を変えても可動壁レール付き梁の基準線は動きません。
- **スポットレール**：可動壁用のレールとは別部材です。主室の長手方向2本と西室側のコンクリート梁の下を通り、取付金具とスポットの支持部材を加えています。中二階の下は推定床下面へ取り付けます。
- **レール定常光**：照明レール下の線状灯として表現し、既存の色温度・照度の設定を保持します。

レール付き梁の下部は、写真に見える開口のある鋼製フレームを簡略化しています。中心線の一致はデータで拘束し、梁の断面・天井高さ・金具の形状や寸法は引き続き推定です。

## 編集と保存

「可動壁」タブ →「配置ラインの座標を編集」でラインを移動・延長・反転すると、対応する天井レールと梁も追従します。元の作品・可動壁の配置は保持し、既存のJSONもそのまま読み込めます。追加の座標を二重に保存せず、床ラインから天井を再生成します。

`src/architecture.js` が共通の形状データです。3D表示・GLB出力・照明の遮蔽計算で同じ形状を使います。スポット灯具と照明レールも同じ取付位置を参照します。梁部材はインスタンス化し、部材が増えても描画呼出しが増えにくい構成です。

## 検証

- `npm test`：床ラインと天井レールの始終点一致、ライン変更・反転への追従、コンクリートのみの梁の保持、スポットレールと灯具の接続を検証。
- `node scripts/ceiling-alignment-test.mjs`：ブラウザーからGLBを書き出し、実際のインスタンスの座標・長さを床ラインと照合。横断ラインのZ変更と中央縦線のX変更後にも一致することを確認。歩行・俯瞰表示も確認。
- 初期データでは可動壁レール付き梁13本、コンクリートのみの梁11本、照明レール8区間。ラインや梁間隔を編集した場合はそのデータに応じて再生成。

結果は `test-results/ceiling-alignment-report.json`、確認画像は `test-results/ceiling-walkthrough.png` と `test-results/ceiling-overview.png` に保存します。テストは独立したブラウザー領域で実行し、通常利用の展示プランを変更しません。
